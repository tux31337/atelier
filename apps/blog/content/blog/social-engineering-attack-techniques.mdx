보안 문제를 공부하다 보면 기술적인 취약점보다 먼저 나오는 주제가 있다. 바로 **사람을 속여 보안 절차를 무너뜨리는 사회공학 기법**이다.  
사회공학은 시스템을 정면으로 뚫기보다, 사람의 심리와 신뢰를 이용해 정보를 빼내는 공격이라는 점이 핵심이다.

이번 글에서는 사회공학 기법의 정의를 먼저 정리하고, 공격 유형을 인간 기반과 컴퓨터 기반으로 나눈 뒤, 시험에서 특히 자주 구분하는 **피싱, 파밍, 스미싱**의 차이를 한 번에 정리해보겠다.

## 사회공학 기법이란 무엇인가

사회공학 기법은 사람들 사이의 **신뢰 관계**를 바탕으로 사람을 속여 정상적인 보안 절차를 무너뜨리고, **비기술적인 수단**으로 정보를 탈취하는 행위를 말한다.

조금 더 쉽게 말하면 공격 대상의 PC를 직접 해킹하지 않더라도,

- 권한 있는 사람처럼 속이거나
- 긴급한 상황처럼 꾸미거나
- 익숙한 기관과 서비스인 것처럼 위장해서

사용자가 스스로 정보를 넘기게 만들면 공격자는 목적을 달성할 수 있다.

그래서 사회공학 문제에서는 늘 다음 문장이 출제 포인트가 된다.

```text
사회공학 기법 = 사람을 속여 비기술적 수단으로 정보를 탈취하는 공격
```

## 사회공학 공격 유형 분류

사회공학 공격은 크게 **인간 기반 공격**과 **컴퓨터 기반 공격**으로 나눌 수 있다.

## 인간 기반 공격

인간 기반 공격은 공격자가 직접 사람에게 접근하거나, 사람의 행동을 관찰하거나, 버려진 자료를 수집하는 방식이다.

| 공격 | 설명 |
|---|---|
| 직접적인 접근 (Direct Approach) | 높은 지위의 사람으로 가장하거나 긴급한 상황처럼 속여 정보를 요구하는 방식 |
| 도청 · 엿듣기 (Eavesdropping) | 대화나 통신 내용을 몰래 청취해 정보를 얻는 방식 |
| 쓰레기통 뒤지기 (Dumpster Diving) | 폐기된 문서, 메모, 출력물, 저장매체 등에서 정보를 수집하는 방식 |
| 어깨너머 훔쳐보기 (Shoulder Surfing) | 화면이나 키보드 입력 장면을 옆에서 몰래 관찰하는 방식 |

이 부류의 공격은 특별한 악성코드가 없어도 성립할 수 있다.  
즉, 보안 수준이 높은 시스템이라도 사용자가 방심하면 정보가 유출될 수 있다는 점이 중요하다.

## 컴퓨터 기반 공격

컴퓨터 기반 공격은 컴퓨터나 네트워크, 온라인 통신 수단을 매개로 사회공학 공격을 수행하는 방식이다.

| 공격 | 설명 |
|---|---|
| 시스템 분석 | 버려진 하드디스크나 컴퓨터를 분석해 정보를 수집하는 방식 |
| 인터넷 기반 | 피싱, 파밍, 스미싱처럼 온라인 매체를 이용해 사용자를 속이는 방식 |

이 중에서도 시험에서 가장 자주 묻는 것은 **피싱, 파밍, 스미싱의 차이**다.

## 피싱, 파밍, 스미싱은 왜 꼭 구분해야 할까

세 공격 모두 최종 목적은 비슷하다.  
사용자를 속여 **개인정보, 금융정보, 인증정보**를 빼내거나, 악성 사이트 접속을 유도하는 것이다.

하지만 **어떤 매개체를 사용하는지**, 그리고 **사용자가 어떻게 가짜 사이트로 이동하게 되는지**가 다르다.  
이 차이를 정확히 구분해야 문제를 헷갈리지 않는다.

## 피싱 (Phishing)

피싱은 **Private data + Fishing**의 합성어로 본다.  
이름 그대로 개인정보를 낚아 올린다는 의미다.

공격자는 신뢰할 만한 기관, 회사, 은행, 택배사, 포털, 관리자로 위장한 **가짜 이메일**을 보낸다.  
사용자가 그 메일 안의 링크를 클릭하거나 첨부파일을 실행하면 가짜 사이트로 이동하거나 악성코드가 실행될 수 있다.

정리하면 피싱의 흐름은 다음과 같다.

```text
피해자 정보 수집
  -> 신뢰할 만한 발신자로 위장한 가짜 이메일 전송
  -> 링크 클릭 또는 첨부파일 실행 유도
  -> 가짜 사이트에서 개인정보 · 금융정보 탈취
```

피싱의 핵심 포인트는 **이메일 기반**이라는 점이다.

## 파밍 (Pharming)

파밍은 **Private data + Farming**의 합성어로 본다.  
피싱처럼 사용자를 속인다는 점은 같지만, 이동 방식이 다르다.

파밍은 사용자가 **정상적인 도메인 주소를 직접 입력했는데도** 가짜 사이트로 연결되게 만드는 공격이다.  
즉, 사용자가 링크를 잘못 눌러서 이동하는 것이 아니라, **정상 주소를 입력했음에도 속는 것**이 핵심이다.

이런 일이 가능한 이유는 다음과 같은 조작 때문이다.

- `hosts` 파일 변조
- 파밍형 악성코드 감염
- DNS 스푸핑 공격

파밍의 흐름은 이렇게 정리할 수 있다.

```text
사용자가 정상 사이트 주소 입력
  -> hosts 파일 또는 DNS 정보가 변조되어 있음
  -> 가짜 사이트로 연결
  -> 개인정보 · 금융정보 탈취
```

파밍의 핵심 포인트는 **정상 주소를 입력해도 가짜 사이트로 이동한다**는 점이다.

## 스미싱 (Smishing)

스미싱은 **SMS + Phishing**의 합성어다.  
피싱의 문자 메시지 버전이라고 생각하면 이해하기 쉽다.

공격자는 택배 조회, 청첩장, 모바일 청구서, 이벤트 당첨, 공공기관 안내처럼 사용자의 관심을 끌 만한 **가짜 SMS 메시지**를 보낸다.  
사용자가 문자에 포함된 링크를 누르면 가짜 사이트로 이동하거나 악성 앱 설치, 소액결제 피해로 이어질 수 있다.

정리하면 스미싱의 흐름은 다음과 같다.

```text
가짜 SMS 메시지 전송
  -> 링크 클릭 유도
  -> 가짜 사이트 접속 또는 악성 앱 설치
  -> 개인정보 · 금융정보 탈취 또는 소액결제 피해 발생
```

스미싱의 핵심 포인트는 **SMS 기반**이며, **소액결제**와 연결될 수 있다는 점이다.

## 피싱, 파밍, 스미싱 비교

세 공격의 차이는 아래 표로 정리하면 가장 빠르게 기억할 수 있다.

| 구분 | 매개체 | 핵심 특징 |
|---|---|---|
| 피싱 | 이메일 | 가짜 이메일을 보내 링크 클릭이나 첨부파일 실행을 유도 |
| 파밍 | DNS · `hosts` 파일 | 정상 주소를 입력해도 가짜 사이트로 이동 |
| 스미싱 | SMS | 문자 메시지 링크 클릭을 유도하며 소액결제로 이어질 수 있음 |

짧게 외우면 이렇게 정리된다.

```text
피싱 = 이메일
파밍 = 정상 주소 입력해도 가짜 사이트
스미싱 = 문자 메시지
```

## 시험에서 특히 자주 나오는 함정

사회공학 문제는 정의보다도 **구분 포인트를 섞어서** 출제하는 경우가 많다.  
다음 세 가지를 특히 조심하면 헷갈릴 일이 줄어든다.

### 1. 피싱과 스미싱을 같은 공격으로 보면 안 된다

둘 다 사용자를 속여 링크를 누르게 만든다는 점은 같지만,  
피싱은 **이메일**, 스미싱은 **SMS**라는 매개체 차이가 분명하다.

### 2. 파밍은 사용자가 실수해서 잘못 들어가는 공격이 아니다

파밍은 사용자가 오히려 **정상적으로 접속하려고 했는데도** 가짜 사이트로 유도되는 공격이다.  
그래서 `DNS 스푸핑`, `hosts 파일 변조` 같은 키워드가 보이면 파밍을 먼저 떠올리는 것이 좋다.

### 3. 사회공학 기법은 기술보다 사람을 노린다는 점이 본질이다

문제에서 보안 절차, 신뢰, 위장, 긴급성, 유도, 사칭 같은 표현이 나오면  
사회공학 문맥일 가능성이 높다.

## 함께 기억하면 좋은 예방 관점

시험을 위한 암기도 중요하지만, 실제 보안 감각으로 연결해두면 더 오래 남는다.

- 출처가 불분명한 이메일 링크와 첨부파일은 바로 열지 않는다.
- 문자 메시지의 URL은 바로 누르지 않고 공식 앱이나 공식 사이트로 직접 확인한다.
- 금융기관, 포털, 공공기관 사이트는 즐겨찾기나 직접 입력으로 접속하되, 접속 이상이 있으면 DNS나 `hosts` 변조 가능성도 의심한다.
- 화면 잠금, 문서 파쇄, 주변 시선 차단처럼 오프라인 정보 노출도 관리해야 한다.

## 한 번에 정리하는 핵심 암기 포인트

마지막으로 시험 직전에 빠르게 훑을 수 있도록 핵심만 압축하면 다음과 같다.

```text
사회공학 기법
  -> 사람의 신뢰를 이용해 비기술적 수단으로 정보 탈취

인간 기반 공격
  -> 직접 접근, 도청, 쓰레기통 뒤지기, 어깨너머 훔쳐보기

컴퓨터 기반 공격
  -> 시스템 분석, 인터넷 기반 공격

피싱
  -> 가짜 이메일

파밍
  -> 정상 주소 입력해도 가짜 사이트
  -> DNS 스푸핑, hosts 파일 변조

스미싱
  -> 가짜 SMS
  -> 링크 클릭, 소액결제 피해 가능
```

사회공학 기법은 결국 시스템이 아니라 **사람의 판단을 우회하는 공격**이다.  
그리고 피싱, 파밍, 스미싱은 모두 비슷해 보이지만 **이메일인지, 정상 주소 입력 상황인지, 문자 메시지인지**를 기준으로 구분하면 훨씬 선명해진다.
