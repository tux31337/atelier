정보보호 개요는 정보보안기사의 가장 앞부분에 나오는 주제지만, 뒤의 접근통제, 암호, 보안관리 파트까지 계속 연결된다.  
특히 **관리적 · 기술적 · 물리적 보안**, **기밀성 · 무결성 · 가용성**, **인증성 · 책임성**은 정의와 예시를 함께 외워야 한다.

이번 글에서는 정보보호의 기본 정의부터 CIA Triad와 확장 요소까지 시험에 필요한 범위로 정리한다.

## 정보보호란 무엇인가

**정보보호**는 조직의 정보자산이 다양한 내외부 위협으로부터 **기밀성, 무결성, 가용성**을 보장받을 수 있도록 관리적, 기술적, 물리적 보호조치를 마련하는 것이다.

짧게 정리하면 다음과 같다.

```text
정보보호 = 정보자산의 기밀성, 무결성, 가용성을 보장하기 위한 보호조치
```

여기서 정보자산은 단순히 파일이나 데이터만 의미하지 않는다.  
시스템, 네트워크, 서비스, 계정, 업무 문서, 로그, 데이터베이스처럼 조직이 보호해야 하는 대상 전반을 포함한다.

시험에서는 예시를 보고 어느 분류인지 고르는 문제가 자주 나온다.

```text
정책, 지침, 조직, 교육 -> 관리적 보안
방화벽, 백신, 보안 설정, 시큐어 코딩 -> 기술적 보안
출입통제, 잠금장치, CCTV, 시설 보호 -> 물리적 보안
```

## 정보보호의 목표: CIA Triad

정보보호의 기본 목표는 **CIA Triad** 로 정리한다.

```text
C = Confidentiality = 기밀성
I = Integrity = 무결성
A = Availability = 가용성
```

이 세 가지는 정보보호의 가장 기본적인 목표다.  
이후 확장 요소로 인증성, 책임성, 부인방지 같은 개념이 함께 붙는다.

## 접근통제 구성요소

기밀성과 무결성을 공부할 때는 접근통제의 세 구성요소도 함께 기억하면 좋다.

```text
주체(Subject) -> 접근을 시도하는 사용자나 프로세스
객체(Object) -> 접근 대상이 되는 정보자산
접근(Access) -> 읽기, 쓰기, 실행, 변경, 삭제 같은 행위
```

즉, 접근통제는 어떤 **주체**가 어떤 **객체**에 어떤 **접근**을 할 수 있는지 통제하는 구조다.

## 기밀성: Confidentiality

**기밀성**은 오직 **인가된 주체**만이 **알 필요성(Need-to-Know)** 에 근거하여 정보자산에 접근하도록 보장하는 성질이다.

쉽게 말하면, 볼 권한이 없는 사람이 정보를 보지 못하게 하는 것이다.

기밀성과 연결되는 대표적인 암호학적 도구는 다음과 같다.

```text
기밀성 도구
  -> 대칭키 암호화
  -> 비대칭키 암호화
```

대칭키 암호화와 비대칭키 암호화는 데이터를 암호화해 인가되지 않은 사용자가 내용을 알 수 없게 한다.

## 무결성: Integrity

**무결성**은 권한 있는 자만이 정보자산에 접근하여 **생성, 변경, 삭제**할 수 있도록 보장하는 성질이다.

핵심은 정보가 허가 없이 바뀌지 않았음을 보장하는 것이다.  
예를 들어 전송 중인 메시지가 중간에서 변경되었는지 확인하는 것도 무결성과 관련된다.

무결성과 연결되는 대표적인 암호학적 도구는 다음과 같다.

```text
무결성 도구
  -> 암호학적 해시함수
  -> 메시지 인증 코드(MAC)
  -> 디지털 서명 / 전자서명
```

해시함수는 데이터가 변경되었는지 확인하는 데 쓰이고, MAC과 디지털 서명은 메시지의 변경 여부와 인증을 함께 다룰 수 있다.

## 가용성: Availability

**가용성**은 권한 있는 자가 정보자산에 접근해야 할 때 **언제든지 접근할 수 있도록** 보장하는 성질이다.

기밀성과 무결성이 정보를 숨기고 보호하는 데 초점이 있다면, 가용성은 서비스가 계속 사용 가능한 상태를 유지하는 데 초점이 있다.

```text
  -> 이중화, 클러스터링, RAID, 백업, 재해복구센터
```

## 인증성: Authenticity

**인증성**은 대상이 주장하는 실체가 맞는지 확인하는 성질이다.  
시험에서는 **사용자 인증**과 **메시지 인증**으로 나눠 정리하면 좋다.

```text

소유 기반 = 가지고 있는 것 = OTP, 스마트카드
존재 기반 = 자신의 것 = 지문, 홍채
```

## 메시지 인증

메시지 인증은 수신한 메시지가 올바른 상대방이 보낸 것임을 인증하는 것이다.

대표 도구는 다음과 같다.

```text
메시지 인증 도구
  -> 메시지 인증 코드(MAC)
  -> 디지털 서명 / 전자서명
```

MAC은 메시지가 변조되지 않았는지와 올바른 키를 가진 상대가 보냈는지를 확인하는 데 쓰인다.  
디지털 서명은 메시지 인증과 함께 부인방지까지 연결된다.

## 책임성: Accountability

**책임성**은 정보자산에 접근하는 자가 접근 결과에 대해 **책임지도록 보장**하는 성질이다.

책임성은 크게 **책임 추적성**과 **부인방지**로 나눠 기억하면 된다.

```text
책임 추적성 = 감사, 로깅
부인방지 = 디지털 서명 / 전자서명
```

특히 **부인방지**는 디지털 서명과 매우 자주 연결된다.  
누가 어떤 행위를 했는지 나중에 부인하지 못하게 하려면 행위 주체를 검증할 수 있는 서명 정보가 필요하기 때문이다.

## 출제 포인트 정리

시험 직전에는 아래 내용만 빠르게 반복해도 좋다.

```text
정보보호
  -> 정보자산의 기밀성, 무결성, 가용성을 보장하기 위한 보호조치

보안 3분류
  -> 관리적 보안, 기술적 보안, 물리적 보안

CIA Triad
  -> 기밀성: 인가된 주체만 알 필요성에 따라 접근
  -> 무결성: 권한 있는 자만 생성, 변경, 삭제
  -> 가용성: 필요할 때 언제든지 접근 가능

접근통제 구성요소
  -> 주체, 객체, 접근

가용성 확보 기법
  -> 장비 이중화, 서버 클러스터링, 디스크 RAID, 백업 및 소산, 재해복구센터

인증 방식
  -> 지식 기반: 패스워드
  -> 소유 기반: OTP, 스마트카드
  -> 존재 기반: 지문, 홍채

책임성
  -> 책임 추적성: 감사, 로깅
  -> 부인방지: 디지털 서명 / 전자서명
```

정보보호 개요는 처음에는 단순 암기처럼 보이지만, 뒤로 갈수록 거의 모든 보안 개념의 기준점이 된다.  
문제에서 암호화가 나오면 기밀성, 해시나 MAC이 나오면 무결성, 이중화나 백업이 나오면 가용성, 로깅이 나오면 책임 추적성, 디지털 서명이 나오면 부인방지까지 함께 떠올리면 된다.
