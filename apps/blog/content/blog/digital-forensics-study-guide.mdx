디지털 포렌식은 침해사고 대응과 보안 조사에서 자주 등장하지만, 정보보안기사 시험에서는 비교적 암기 포인트가 뚜렷한 주제다.  
핵심은 **법적으로 유효한 증거**를 어떻게 수집하고, 변경 없이 보관했음을 어떻게 입증하는지다.

이번 글에서는 디지털 포렌식의 정의, 기본원칙 5가지, 절차, 안티 포렌식, 그리고 윈도우 휘발성 데이터 수집 명령어를 한 번에 정리한다.

## 디지털 포렌식이란 무엇인가

**디지털 포렌식**은 침해사고 발생 시 디지털기기로부터 **법적으로 유효한 증거**를 수집, 분석, 보관, 제출하는 일련의 과정을 다루는 과학 분야다.

짧게 줄이면 다음과 같다.

```text
디지털 포렌식 = 디지털 증거를 법적으로 유효하게 다루는 절차와 기술
```

여기서 중요한 점은 단순히 데이터를 찾는 것이 아니라는 점이다.  
증거로 인정받기 위해서는 수집 방법, 분석 과정, 보관 상태, 제출 절차가 모두 설명 가능해야 한다.

디지털 포렌식의 기본 배경으로 자주 언급되는 것이 **로카르드의 교환법칙**이다.

```text
로카르드의 교환법칙
  -> 범죄자는 범죄 현장을 드나들 때 흔적을 남기고,
     무언가를 가지고 떠난다.
```

디지털 환경에서도 마찬가지다. 공격자는 로그, 프로세스, 네트워크 연결, 파일 흔적, 계정 사용 기록 같은 디지털 흔적을 남길 수 있다.

암기 순서는 **정 · 재 · 무 · 신 · 연**으로 잡으면 좋다.

```text
정 · 재 · 무 · 신 · 연
  -> 정당성, 재현성, 무결성, 신속성, 연계 보관성
```

```text
무 = 위변조 없음
신 = 휘발성 때문에 빠르게
연 = 수집부터 제출까지 승계 내역 기록
```

## 연계 보관성: Chain of Custody

**연계 보관성(CoC, Chain of Custody)** 은 디지털 증거가 수집된 뒤 법정에 제출될 때까지 변경 없이 관리되었음을 입증하는 원칙이다.  
**보관의 연속성 원칙**이라고도 한다.

단계는 다음 순서로 외우면 된다.

```text
수집(획득) -> 이송(이동) -> 보관 -> 분석 -> 법정 제출
```

핵심은 증거물 관리 주체가 바뀔 때마다 누가, 언제, 어떤 상태로 증거를 넘겨받았는지 기록하는 것이다.  
이 기록이 있어야 증거가 중간에 변경되거나 훼손되지 않았다는 점을 설명할 수 있다.

```text

```

메모리, 네트워크 연결, 실행 중인 프로세스, 로그인 세션처럼 시스템을 끄거나 시간이 지나면 사라질 수 있는 정보는 먼저 확보해야 한다.

## 출제 포인트 정리

마지막으로 시험 직전에 볼 내용만 압축하면 다음과 같다.

```text
디지털 포렌식
  -> 법적으로 유효한 증거를 디지털기기로부터 수집, 분석, 보관, 제출

로카르드의 교환법칙
  -> 범죄자는 흔적을 남기고 무언가를 가지고 떠난다

기본원칙 5가지
  -> 정당성, 재현성, 무결성, 신속성, 연계 보관성
  -> 정 · 재 · 무 · 신 · 연

연계 보관성
  -> 수집 -> 이송 -> 보관 -> 분석 -> 법정 제출

증거 수집
  -> 휘발성이 높은 것부터 수집

안티 포렌식
  -> 데이터 은폐, 디스크 와이핑, 디스크 디가우징
  -> 와이핑은 덮어쓰기
  -> 디가우징은 자성 제거

netstat -anob
  -> o = PID
  -> b = 실행파일명
```

디지털 포렌식 문제는 긴 설명보다 키워드 대응이 중요하다.  
**정 · 재 · 무 · 신 · 연**, **수집 → 이송 → 보관 → 분석 → 법정 제출**, **휘발성 높은 것부터**, **와이핑은 덮어쓰기, 디가우징은 자성 제거**만 정확히 잡아도 대부분의 선택지는 빠르게 걸러낼 수 있다.
