침해사고 대응은 정보보안기사에서 **절차 순서**와 **사고 조사 단계**가 자주 출제되는 주제다.  
특히 7단계를 순서대로 외우고, 5단계 사고 조사에서 데이터 수집과 데이터 분석을 구분할 수 있어야 한다.

이번 글에서는 침해사고의 정의, 대응 절차 7단계, 사고 조사 단계의 서술 포인트를 시험 대비 관점으로 정리한다.

## 침해사고란 무엇인가

**침해사고**는 해킹, 컴퓨터바이러스, 논리폭탄, 메일폭탄, 서비스거부, 고출력 전자기파 등 **전자적 침해행위**로 인해 정보통신망 또는 정보통신기반시설을 공격하는 행위로 발생한 사태를 말한다.

짧게 보면 다음과 같다.

```text
침해사고 = 전자적 침해행위로 정보통신망 또는 정보통신기반시설에 피해가 발생한 사태
```

문제에서는 침해사고의 예시로 다음 표현이 함께 나올 수 있다.

```text
해킹
컴퓨터바이러스
논리폭탄
메일폭탄
서비스거부
고출력 전자기파
```

## 1단계: 사고 전 준비

사고 전 준비 단계는 침해사고가 발생하기 전에 대응 체계를 마련하는 단계다.

핵심은 **침해사고대응팀(CERT)** 을 조직하고, 사고가 발생했을 때 누가 무엇을 할지 미리 정해두는 것이다.

```text
사고 전 준비
  -> CERT 조직
  -> 대응 절차 준비
  -> 도구와 연락 체계 준비
```

## 2단계: 사고 탐지

사고 탐지는 이상 징후를 확인하고 침해사고 발생을 식별하는 단계다.

탐지는 다음 장비와 시스템을 통해 이루어질 수 있다.

```text
정보보호 장비
네트워크 장비
통합보안관제시스템
```

이 단계의 핵심 표현은 **이상 징후 확인**과 **침해사고 식별**이다.

## 3단계: 초기 대응

초기 대응은 사고가 식별된 직후 기본적인 조치를 수행하는 단계다.

주요 작업은 다음과 같다.

```text
사고 초기 조사
사고 상황에 대한 기본 사항 기록
침해사고대응팀 신고 및 소집
관련 부서 통지
```

초기 대응 단계에서는 깊은 분석보다 사고 상황을 빠르게 파악하고 대응 조직을 움직이게 하는 것이 중요하다.

## 4단계: 대응 전략 체계화

대응 전략 체계화 단계에서는 현재 상황에서 어떤 방식으로 대응할지 결정한다.

시험에서는 다음 키워드를 특히 잘 봐야 한다.

```text
최적의 대응 전략 결정
관리자 승인 획득
소송 필요 여부 결정
수사기관 공조 여부 판단
```

여기서 **관리자 승인**과 **수사기관 공조 여부 판단**은 출제 포인트다.  
기술 조치만 하는 단계가 아니라, 조직적이고 법적인 대응 방향까지 정하는 단계로 이해하면 된다.

## 5단계: 사고 조사

사고 조사는 침해사고 대응 절차에서 서술형으로도 물어볼 수 있는 핵심 단계다.

이 단계에서는 데이터 수집과 분석을 통해 다음 질문에 답해야 한다.

```text
언제 사고가 발생했는가
누가 관련되어 있는가
어떻게 사고가 일어났는가
피해 확산을 어떻게 막을 것인가
재발을 어떻게 방지할 것인가
```

조사는 크게 **호스트 기반 증거**와 **네트워크 기반 증거**로 나누어 수행한다.

## 사고 조사: 데이터 수집

데이터 수집은 사고 조사 단계의 첫 번째 핵심 작업이다.

수집 대상은 다음처럼 나눌 수 있다.

데이터 수집에서 가장 중요한 원칙은 **휘발성 데이터부터 먼저 수집**하는 것이다.

```text
휘발성 데이터 먼저 수집
  -> 사라지기 전에 현재 상태 확보
  -> 이후 포렌식 이미징 작업 수행
```

휘발성 증거는 사고 의도 파악과 시스템 **스냅샷(Snap-shot)** 제공에 도움이 된다.  
예를 들어 실행 중인 프로세스, 네트워크 연결, 메모리 정보처럼 시스템 상태가 바뀌면 사라질 수 있는 데이터가 여기에 해당한다.

이후에는 디스크 등을 대상으로 **포렌식 이미징**을 수행해 분석 가능한 사본을 확보한다.

이 분석을 **포렌식 분석**이라고도 한다.

## 6단계: 보고서 작성

보고서 작성 단계에서는 사고에 대한 정확한 보고서를 작성한다.

여기서 중요한 점은 보고서의 대상이다.  
보고서는 기술자만 보는 문서가 아니라 **의사결정자**가 보고 판단할 수 있어야 한다.

```text
보고서 작성
  -> 의사결정자가 쉽게 이해할 수 있는 형태
  -> 사고 내용, 원인, 피해 범위, 대응 결과, 재발 방지 방안 정리
```

## 7단계: 해결

해결 단계는 단순히 시스템을 복구하는 것으로 끝나지 않는다.  
향후 유사 공격을 식별하고 예방할 수 있도록 조직의 보안 정책과 프로세스를 고치는 단계까지 포함한다.

주요 작업은 다음과 같다.

```text
유사 공격 식별 및 예방을 위한 보안 정책 수립
현재 문제가 되는 조직 프로세스 수정
복구 결과 확인
재발 방지 대책 반영
```

즉, 해결 단계는 복구와 개선을 함께 포함한다고 보면 된다.

## 출제 포인트 정리

침해사고 대응 문제는 순서와 사고 조사 세부 내용이 핵심이다.

```text
침해사고 대응 7단계
  -> 사고 전 준비
  -> 사고 탐지
  -> 초기 대응
  -> 대응 전략 체계화
  -> 사고 조사
  -> 보고서 작성
  -> 해결

짧은 암기
  -> 준비 -> 탐지 -> 초기대응 -> 전략체계화 -> 사고조사 -> 보고서 -> 해결

4단계 대응 전략 체계화
  -> 관리자 승인
  -> 소송 필요 여부
  -> 수사기관 공조 여부 판단

5단계 사고 조사
  -> 데이터 수집 + 데이터 분석

데이터 수집
  -> 호스트 기반 증거
  -> 네트워크 기반 증거
  -> 기타 증거
  -> 휘발성 데이터 먼저 수집
  -> 이후 포렌식 이미징

데이터 분석
  -> 로그 파일
  -> 시스템 설정 파일
  -> 웹 브라우저 히스토리
  -> 이메일 및 첨부파일
  -> 설치된 애플리케이션
```

마지막으로 한 줄로 압축하면 이렇게 정리할 수 있다.

```text
침해사고 대응은 준비, 탐지, 초기대응, 전략체계화, 사고조사, 보고서, 해결 순서로 진행하며,
사고 조사는 휘발성 데이터 수집 후 포렌식 이미징과 분석으로 이어진다.
```

순서 문제에서는 단계 이름이 조금 다르게 나와도 흐름을 보면 된다.  
먼저 준비하고, 탐지하고, 초기에 대응한 뒤, 전략을 세우고, 조사하고, 보고하고, 마지막에 복구와 개선으로 닫는다.
